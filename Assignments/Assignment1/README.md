# Assignment 1

This folder contains my work for Assignment 1. The assignment covers univariate statistics, regression, correlation, conditional distributions, and time-series models.

## Files

- `responses.pdf` contains the written answers and figures.
- `problem.py` contains the code for Problems 1 through 5.
- `problem1.csv` through `problem5.csv` contain the input data.

## Requirements

- Python 3
- pandas
- NumPy
- SciPy
- Matplotlib
- statsmodels

Install the required packages with:

```bash
python -m pip install pandas numpy scipy matplotlib statsmodels
```

## Run the Code

Keep the Python file and all CSV files in the same folder. Open a terminal in this folder. Then run:

```bash
python problem.py
```

The script prints all numerical results in the terminal. It also creates the following figures:

- `problem1_hist.png`
- `problem2_scatter.png`
- `problem3_pairs.png`
- `problem4_conditional.png`
- `problem5_acf_pacf.png`

These results and figures reproduce the analysis in the PDF report.
